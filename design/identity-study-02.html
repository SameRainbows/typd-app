Typd · brand identity · study 02

Surviving sixteen pixels was the entry fee. This study looks for a mark.

Five new marks for Typd, set against the icon that ships today and study 01's Slug. Each one is drawn as a function of its pixel size, judged in a Windows tray and a macOS menu bar, made into an app icon for both platforms, and locked up with a drawn wordmark. The recommendation is 03 Ligature.

Where we are

The icon that ships

The app icon, the favicon and the site header all draw the overlay pill with a red dot at its right end. A pill does not fit a 16 px tray, so trayIcon() draws a filled circle instead. It reads as a toggle switch in the on position. The red dot is a recording light, which makes the mark about audio, and it spends the one danger red that Law 7 keeps for errors. The tray circle is a status light: it says nothing about Typd and shares nothing with the app icon.

tray · 16
32

Study 01's Slug, never shipped

Crisp at 16 px and on thesis, which is why it won. But a rounded rectangle with two bars knocked out of it is a stock glyph: Material's subtitles icon and a dozen notes icons are drawn the same way. Nothing in it comes from Typd, so you could not pick it out of an icon font as ours, or draw it from memory. It passed the pixel test and failed the logo test.

The brief, restated

Kept from study 01. Text, never audio: no microphone, no waveform, no bubble. Mass, not stroke, because a 1.5 px line is a grey smear at 16 px. Monochrome in both polarities, #F4F5F7 on dark and #14161B on light. Straight edges on whole pixels.

New: it has to be ours. A shape that belongs to a category is not a mark. Every concept here starts from something only Typd has: its name, its letters, or the precise job it does to a sentence.

New: no red. The red stays where the roadmap put it: errors in the pill, struck-out words on the website.

New: hinted at every size, not scaled from 16. Windows asks the tray for 16, 20, 24 or 32 px depending on display scaling. A macOS menu-bar template is 16, 18 or 22 pt at @1x and @2x, so 16 to 44 px. A 16-unit drawing scaled to 24 puts every odd coordinate on a half pixel. So each mark below is a short function of its pixel size: stems, gaps and margins are re-rounded for every size, and the SVGs in assets/brand come out of the same function.

Four outputs, two platforms. The Windows tray, the macOS menu bar, the app icon (Windows .ico from 16 to 256; macOS 1024 on the Big Sur grid, split into Icon Composer layers for macOS 26), and the lockup on typd.mehmetdedeler.com.

Every raster on this page is drawn at your screen's real pixel count (devicePixelRatio 1). On a 150 % display the cell captioned 16 is a 24-pixel drawing, which is exactly the image Windows asks the tray for at that setting. The 16 cell is boxed: it decides.

Five concepts, and the baseline

00

Pill

Ships today · baseline

The overlay pill with a red dot, in a dark tile; in the tray, a filled circle of radius size / 2 − 1. Shown at the same sizes and in the same settings as the new concepts, so every comparison below has a floor.

Holds
The pill is the right object to care about: it is the whole product surface. The dark tile is calm and reads at Dock size.
Fails
A toggle switch, a recording light, and a red that belongs to errors. The tray and the app icon share nothing, and the tray circle is the softest drawing on the page: at 16 px.
Verdict
Replace. Keep the pill in the overlay, where it is the product, and keep the red for errors.
01

Selection

Refinement of Slug

The Slug's weakness was its container. Take it away and let the block take the shape its text gives it. Select three lines that start mid-sentence and most editors draw the same staircase: the first line from where you clicked to the margin, the middle line full, the last line stopping where you let go. The mark is that highlight with its text knocked out. It is the moment revise mode begins, and it keeps everything the Slug got right: mass, whole pixels, and lines knocked out of the fill so the mark inverts for free.

Holds
Zero partial pixels at every size from 16 to 44. The staircase is the only silhouette in the study that every user has already drawn, thousands of times, with a mouse.
Fails
Three lines and two steps is a lot of event for 16 pixels: in the tray it is a busy little stack, and as an app icon it can read as stacked bricks. It also ties the identity to one feature, revision, which is the trap study 01 warned about.
Verdict
The best refinement of the Slug, and the right glyph for the revise state in the overlay. Not the mark.
02

Past tense

Slug, cast as a letter

One letter turns type into typed. The d is the part of the name that says the work is already done, which is the whole promise: you speak, and the text is finished. Cast that d as a slug: a solid bowl with two set lines knocked out of it, the second stopping short, and the ascender rising from its right side. It keeps the Slug's material and finally gives it a letter, so the shape belongs to the name.

Holds
Reads as a d at every size, and as a d made of text from 64 px up. Crisp: the only partial pixels are the two rounded corners on the bowl side, spent so it reads as a letter and not as a box with a tab.
Fails
At 16 px the set lines are 2 px slots in a 14 px letter, so the read is "a d with something in it". With the ascender at one corner the silhouette sits close to a folder or a clipboard. And a lone d in the tray says d, not Typd.
Verdict
A real step up from the Slug and the safest option here. It has less presence than 03 or 04.
03

Ligature

Monogram cut from a drawn wordmarkRecommended

Typd's last two letters are the same shape: a p turned over is a d. Draw them as a ligature and they share one bowl, with the p's descender on the left and the d's ascender on the right. That is the product's central claim drawn as a letter: one model, not two. The usual design chains a recogniser to a cleanup model; in Typd the hearing and the writing share one body. The glyph is rotationally symmetric, two stems and one bowl, and its counter is a stadium: the overlay pill, sitting inside the letter. The mark is cut out of the wordmark rather than placed beside it, so the logo and the name are one drawing.

Holds
Ownable: no system glyph or category icon looks like it, and it comes from the name. Every outer edge is straight and lands on a whole pixel at every size; the only partial pixels are the round ends of the counter ( at 16 px). Twelve pixels wide and full height, it sits in a tray like a character of type: about the footprint of the outlined system glyphs, and the only solid among them.
Fails
In the wordmark, a shared bowl can read as "typ" on first sight. Standalone at 16 px nobody reads "pd"; they see a glyph, which is fine for a mark. The wordmark risk is real, so it gets a test before it ships (below).
Verdict
Recommended.
04

Apostrophe

Punctuation

Typd is typed with a letter taken out, and English already has a mark for exactly that: the apostrophe, as in typ’d. The same glyph closes a quotation, so it is also how writing marks somebody speaking. One heavy comma carries both the name's construction and the product's job, speech into text, without drawing a microphone. It is also the tray circle you have today, given a tail: the dot that is already there becomes a mark that means something.

Holds
The strongest silhouette in the set. Nothing in a tray or a menu bar is shaped like it, so it is found at a glance, and it is warm where the rectilinear marks are cool. As an app icon it is the most confident tile on the sheet.
Fails
It is all curve, so at 16 px it is mostly antialiased edge (). Small, it can read as a 9 or a raindrop. The lockup typ’d will teach people to spell the name with an apostrophe. And a comma is easy to admire and hard to own.
Verdict
Runner-up. If the read-aloud test sinks the Ligature's wordmark, this is the one to take, with the name set as plain typd.
05

Omission

Editorial mark

When an editor quotes somebody and cuts the words that add nothing, the cut is marked [...]. It is the trade's own sign for what Typd does to a dictation: the ums, the false start and the "Tuesday, actually" come out, and what is left is still what the speaker meant. The square brackets are themselves the editor's sign for words that are the writer's, not the speaker's. No dictation tool has borrowed from the conventions of quotation, which is where this product actually lives.

Holds
Zero partial pixels at every size: 2 px stems and three 2 × 2 dots with a pixel between them, every one of which survives at 16. The most precise idea in the set.
Fails
Five separate pieces in sixteen pixels. In a tray [...] reads as an overflow menu or a placeholder, and on a Mac it sits beside the ellipsis that means "more". Anyone who has seen a JSON array reads it as code.
Verdict
Cut as a mark. Keep the idea as a line for the website, where a sentence can explain it.

App icon · macOS and Windows

One graphite tile for every concept, so the comparison is between marks: a gradient from #2B2E35 to #121317, a hairline of light on the top edge, and the mark in near-white. Every .ico frame

Wordmark

Drawn, not typeset. Study 01 set the name in Bahnschrift; a font that ships with Windows cannot become a logo without its licence coming along, and it shares nothing with the mark. So typd is drawn on the Ligature's own construction: stems of 2 units, an x-height of 8, ascenders and descenders of 4, and every bowl a stadium. Every counter in the word is the overlay pill. Lowercase, because the ligature only exists in lowercase, and because the word reads as a thing that was written.

Recommendation

Recommended

03 Ligature, with the drawn wordmark, on a graphite tile.

It is the only candidate that is both crisp and owned.

Selection, Past tense and Omission hold the grid as well or better, and each is a shape that already belongs to something: a highlight, a d, a pair of brackets. The Apostrophe is owned and memorable and cannot hold the grid. The Ligature does both. Its outline is straight lines on whole pixels at every size, and its shape exists only because Typd's name ends in p and d.

It carries the claim the site leads with. One model that hears and writes in one step is what the README measures: better dictation than a recogniser plus a cleanup model, in about a third of the time. Two letters around one bowl says it without a caption. The counter is the pill, so the mark also holds the product surface.

It makes one system. The mark is cut from the wordmark, the wordmark's other bowls are the same stadium, and the app icon is the mark on a graphite tile. Nothing needs a second idea, and nothing is borrowed from a font.

The risk, and the test. The wordmark has to be read correctly by people who have never seen it. Before it ships, show the lockup at 20 px and at 72 px to five people cold and ask them to read it aloud (Law 5). If more than one says "typ", keep the mark and set the name as plain typd (wordmark-plain.svg). The system loses one trick and nothing else.

Specification

GridN × N at the size it will be shown: 16, 20, 24, 32 in the tray; 16 and 32 in the menu bar. Never scaled from another size.
Stemmax(1, round(N / 8)). The bowl's top and bottom are the same weight.
Ascender, descenderround(N / 4) each; the bowl is what is left.
Bowl widthNearest whole number to 12N / 16 that leaves an even margin, so the glyph is centred on whole pixels.
CounterA stadium inset one stem into the bowl. Its round ends are the only curves in the mark.
ColourTray: #F4F5F7 on a dark taskbar, #14161B on a light one, following nativeTheme. Menu bar: black and alpha, as a template. Never a third value, never red.
Clear spaceOne ascender (a quarter of the mark's height) on every side. In the tray, nothing beyond the OS cell: padding there only shrinks the mark.
NeverOutline it, slant it, round its outer corners, open the counter, separate the stems from the bowl, put it in a second container.

Per size, from the geometry

Drop-in tray code

The same geometry as a replacement for trayIcon() in src/main/index.js, not applied. Each display scale gets its own drawing, and macOS gets a template image. Alternatively load the PNGs exported from px/, named tray.png, tray@1.25x.png, tray@1.5x.png, tray@2x.png; Electron picks the right one.

/**
 * Typd's tray mark: the ligature. The p and the d of "typd" share one bowl.
 * Drawn at the pixel size each display scale asks for (16, 20, 24, 32) rather
 * than scaled from 16, so every straight edge lands on a whole pixel.
 */
function ligature(N) {
  const w = Math.max(1, Math.round(N / 8));         // stem = bowl weight
  const a = Math.round(N / 4);                      // ascender and descender
  const ideal = N * 12 / 16;                        // bowl width, stems included,
  let W = null;                                     // kept centred on whole pixels
  for (let c = Math.floor(ideal) - 1; c <= Math.ceil(ideal) + 1; c++)
    if ((N - c) % 2 === 0 && (W === null || Math.abs(c - ideal) < Math.abs(W - ideal))) W = c;
  const x0 = (N - W) / 2;
  return { w, top: a, bot: N - a, x0, x1: x0 + W };
}

function trayBitmap(N, [R, G, B]) {
  const ss = 4, big = N * ss, buf = Buffer.alloc(big * big * 4);
  const { w, top, bot, x0, x1 } = ligature(N);

  // the counter: a stadium inset one stem into the bowl, the overlay pill's shape
  const c = { x0: x0 + w, x1: x1 - w, y0: top + w, y1: bot - w };
  const r = Math.min(c.x1 - c.x0, c.y1 - c.y0) / 2;
  const inCounter = (x, y) => {
    if (x < c.x0 || x >= c.x1 || y < c.y0 || y >= c.y1) return false;
    const qx = Math.min(Math.max(x, c.x0 + r), c.x1 - r);
    const qy = Math.min(Math.max(y, c.y0 + r), c.y1 - r);
    return (x - qx) ** 2 + (y - qy) ** 2 <= r * r;
  };
  const inMark = (x, y) =>
    (x >= x1 - w && x < x1 && y < bot) ||                 // d: ascender, right of bowl
    (x >= x0 && x < x0 + w && y >= top) ||                // p: descender, left of bowl
    (x >= x0 && x < x1 && y >= top && y < bot && !inCounter(x, y));

  for (let py = 0; py < big; py++) {
    for (let px = 0; px < big; px++) {
      if (!inMark((px + 0.5) / ss, (py + 0.5) / ss)) continue;
      const i = (py * big + px) * 4;
      buf[i] = B; buf[i + 1] = G; buf[i + 2] = R; buf[i + 3] = 0xff;
    }
  }
  return nativeImage.createFromBitmap(buf, { width: big, height: big })
    .resize({ width: N, height: N, quality: 'best' });
}

function trayIcon(dark = nativeTheme.shouldUseDarkColors) {
  const img = nativeImage.createEmpty();
  if (process.platform === 'darwin') {              // template: alpha only, macOS paints it
    for (const s of [1, 2]) {
      img.addRepresentation({ scaleFactor: s, width: 16 * s, height: 16 * s,
                              buffer: trayBitmap(16 * s, [0, 0, 0]).toBitmap() });
    }
    img.setTemplateImage(true);
    return img;
  }
  const ink = dark ? [0xF4, 0xF5, 0xF7] : [0x14, 0x16, 0x1B];
  for (const s of [1, 1.25, 1.5, 2]) {              // 16, 20, 24, 32 px
    const N = Math.round(16 * s);
    img.addRepresentation({ scaleFactor: s, width: N, height: N,
                            buffer: trayBitmap(N, ink).toBitmap() });
  }
  return img;
}

// The taskbar flips; so does the mark.
nativeTheme.on('updated', () => { if (tray) tray.setImage(trayIcon()); });
