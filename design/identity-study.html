Typd · brand identity · study 01

The mark, the wordmark,
and the sixteen pixels
that decide both.

Six candidate marks, tested where they will actually be seen: a 16 pixel monochrome tile in a Windows tray, next to a volume glyph and a battery.

The brief, restated as constraints

Text, never audio. Wispr Flow, superwhisper and Typeless all draw a microphone or a waveform. That is a picture of the input. Typd's subject is the output — the sentence you meant. The mark is made of typographic material: rules, measures, carets, set lines. No mouth, no wave, no bubble.

Mass, not stroke. At 16 px a 1.5 px stroke is a grey smear. Everything that survives at that size is a silhouette. So the candidates are judged on the shape of their solid, not the cleverness of their line.

Monochrome, both polarities. The taskbar flips with the OS theme and the mark flips with it. Near-white #F4F5F7 on dark, near-black #14161B on light — the same ramp the overlay already uses. Any mark that needs a fill and a background is disqualified.

Whole pixels. The tray icon is drawn procedurally into a BGRA buffer, supersampled 4× and downscaled. A mark whose edges land on whole grid units at 16 px comes out of that pipeline crisp. One whose edges land on halves comes out soft. This is a design decision, not an implementation detail.

Every concept below is shown at 16, 24, 32, 64 and 256 px, white-on-dark and black-on-light. The 16 px cell is boxed. That is the only column that decides anything; the others exist to confirm the mark does not fall apart on the way up.

Six concepts

01

Elision

The name is typed with the vowel taken out — which is the product's whole argument: what you meant, not what you literally said. So draw the word as its own vertical rhythm. Ascender, descender, descender, nothing, ascender. T y p · d. The gap is where the e was, and the gap is the mark.

Holds
Unmistakably typographic, and the only concept that encodes the name rather than a feature. Beautiful at 64 and up — it reads as a word you almost recognise.
Fails
At 16 px the four stems sit on a 3.4-unit pitch, so nothing lands on a whole pixel; every stem is a soft grey column. The differing heights that make it a skyline at 256 px collapse into noise, and what is left reads as a barcode. It also loses the argument to the taskbar: four thin verticals is what a signal-strength meter looks like.
Verdict
The idea is right and the execution cannot be made to fit sixteen pixels. Keep it for the loading state, the installer, the website hero.
02

Insertion

Typography already has a mark for what you meant goes here: the copyeditor's caret, set beneath the line, apex touching it. Typd's new feature is exactly that gesture — select the line, say the correction, it lands in place. Borrowed from the trade rather than invented, which is the honest kind of borrowing.

03

Slug

In hot metal, a slug is one line of type cast solid — finished, single-piece, the thing you set out to make. Draw it as a solid block with the lines knocked out of it, flush left and ragged right. The second line stops at three fifths of the measure, and the void after it is the part you didn't have to say. It is also, precisely, what selected text looks like on any operating system ever shipped.

Holds
Every edge except the four corners lands on a whole pixel at 16 px. It is not an antialiased approximation of a shape — it is a hand-set bitmap that happens to also be a vector. Mass-first, so the silhouette is the loudest thing in a tray of hairline system glyphs, and it inverts natively: knocking out the lines is the inversion.
Fails
The nearest collision is the closed-caption glyph — a rounded box with dashes in it. Defused by three decisions: the fill is solid rather than outlined, the corner radius is 1.5 units (a cast edge, not a friendly one), and the lines are flush left with a ragged right rather than centred. Flush-left/ragged-right is the signature of prose; centred short dashes is the signature of subtitles.
Verdict
Recommended. Full spec below.
04

Return

Every competitor is write-only: the text goes out and that is the end of it. Typd comes back. One line runs out to the measure, turns, and returns part of the way — stopping where the selection stops. A closed loop drawn as two lines of type sharing a turn.

05

Overwrite

Revision is two texts trying to occupy the same place. Draw both as solid bars and let the overlap cancel — where the new text lands, the old one is simply gone. A constructivist device: the meaning is in the subtraction, not in a symbol standing for it.

06

Beam

The I-beam is the one glyph in computing that means text is about to happen here, and every rival ignored it in favour of a microphone. Take the thing the OS already draws and claim it. Maximum thesis alignment: it is not an app's logo, it is a piece of the operating system.

But both are crisp because they are trivial: an orthogonal step and a cursor. The Slug is the only candidate that carries the argument and holds the grid, and its seven partial pixels are not failure — they are the corner radius, put there on purpose so the block reads as a cast object rather than a raw rectangle. That is a spent pixel, not a lost one.

Wordmark

Strict CSP, no external font loading: the wordmark has to be set in something already on the machine. That is less of a constraint than it sounds — Windows 11 ships a DIN, a variable humanist sans and a good gothic. Three treatments, for the three marks that reached the shortlist.

One decision applies to all three: the word is set plainly. No gap opened between p and d, no ghosted e, no underscore standing in for the missing vowel. The elision is already in the name. Drawing attention to it in the wordmark is explaining the joke.

Why. Bahnschrift is Microsoft's variable DIN — metrically compatible with DIN 1451, the German engineering-drawing standard that Braun and Teenage Engineering both live inside. It is a face made for labelling machines, which is exactly what a wordmark next to a tray icon is doing. It ships with every Windows 10 build from 1709 and every Windows 11, and it is variable, so weight and width are continuous rather than four cut files.

The name happens to set beautifully in it. T y p d is cap · descender · descender · ascender: two verticals bracketing two descenders, a symmetry Bahnschrift's flat, unmodulated terminals make plain. The straight diagonal on the y and the perfectly vertical stem on the d stop it going soft. Set at SemiBold with +1.2% tracking so the four letters read as four assembled parts rather than a fused word.

At 60 px the y's curved tail and the p's soft shoulder make the word look like a dialog heading rather than a mark. Being indistinguishable from the OS is a virtue in the overlay and a problem on a landing page. Hold it as the fallback for any surface where Bahnschrift cannot be guaranteed.

Why. Monospace makes the elision structural: in a fixed-width face every character occupies one cell, so a four-cell word that ought to be five is visibly short. It is the only setting where the missing vowel is felt without being pointed at. Cascadia is Microsoft's own and ships with Windows 11; Consolas is the fallback on anything older.

Why not. Monospace signals developer tool, and Typd is for anyone who writes. It also chains the wordmark to the Beam, and the Beam is cut. Shown because the argument is real and someone will raise it.

Recommendation

Typd

03 Slug, set with the wordmark in Bahnschrift SemiBold.

It wins on the only criterion that was ever going to decide this. At 16 pixels every straight edge sits on a whole-pixel boundary, so it does not survive the rasteriser — it ignores it. Seven of its 142 inked pixels are partial and all seven are the corner radius, spent deliberately. The same drawing is correct on a 100% display and a 200% one.

Two other candidates rasterise cleaner. Neither means anything: Overwrite is a shape in search of a story, and Beam is a mouse cursor. The Slug is the only one on the sheet that holds the grid and holds an argument, which is the whole job.

It is also the only candidate that is about the whole product rather than one feature of it. The Insertion caret and the Return hairpin both illustrate revision, which is this year's differentiator and next year's checkbox. The Slug is a finished line of type with the part you didn't have to say left blank — dictation and revision are the same picture, and it will still be the right picture when the feature list has moved on.

And it does the thesis. A solid block with lines knocked out of it is what the operating system draws when text is selected; the mark is borrowed from the same vocabulary the overlay is written in, so it reads as a part of Windows that happens to be yours rather than an app announcing itself.

Specification

The 16 px bitmap, from the geometry.
Solid = fully inked · half-tone = corner radius.
138 solid + 4 corner = 142 inked. A real rasteriser
spreads those corners over 7 pixels; see the count above.

Grid16 × 16 units. One unit = one pixel at the tray size, so the drawing and the bitmap are the same document. Every coordinate is a whole unit except the corner radius.
Blockx 1 → 15, y 2 → 14 — 14 × 12 units, ratio 7:6. Corner radius 1.5. Not square, not a page: landscape, because a line of set type is wider than it is tall. The 1-unit side bearing and 2-unit top/bottom bearing keep it the same optical weight as the outlined system glyphs it sits beside.
Measurex 4 → 12 — 8 units, inset 3 from each block edge. That inset is the mark's only stem width and it never changes.
Line 1x 4 → 12, y 5 → 7 — full measure, 2 units tall.
Line 2x 4 → 9, y 9 → 11 — 5 of 8 units, 62.5% of the measure. The 3 units of solid after it are the elision. Flush left, ragged right; never centred, never justified.
Leading3 units above, 2 between, 3 below — 3·2·2·2·3 = 12. The interline gap equals the line weight, which is what makes it read as a dense block of set type rather than a list.
Fill ruleEven-odd. The lines are knocked out, never painted in a second colour. This is what makes the mark invert for free: flip the fill and the mark is already correct.
ColourNear-white #F4F5F7 on dark, near-black #14161B on light — the overlay's existing ramp. Follow nativeTheme.shouldUseDarkColors and redraw on nativeTheme 'updated'. Never any third value.
Clear space2 units on every side of the 16 × 16 tile — one eighth of the tile. In a lockup that is 0.125 × mark width minimum, and the gap to the wordmark is 4 units (one line-plus-leading). In the tray, the OS cell already provides more than this: do not add padding there, or the mark shrinks below its neighbours and loses the only advantage it has.
LockupMark cropped to the block (viewBox "1 2 14 12") and set to the wordmark's cap height. Horizontal only. The stacked lockup does not exist; if there is no room for the horizontal one, use the mark alone.
NeverOutline it. Round the corners further. Centre the lines. Add a third line. Tilt it. Put it in a container. Give it colour.

Bonus · the mark as the procedural bitmap

A drop-in replacement for trayIcon() in src/main/index.js. Same shape as the existing function — allocate BGRA, supersample 4×, let the downscale antialias — but the geometry is declared in grid units rather than pixels, so the spec above and the code are the same numbers.

Note what falls out of the whole-pixel grid: at size = 16 one grid unit is exactly 4 supersampled pixels, so every straight edge in the mark falls on a 4-pixel block boundary and the downscale has nothing to blend except the corners. Measured against the vector: 7 of 256 pixels come back partial, 2.7% of the tile, and all of them are radius. The supersample earns its cost on the corners and is a no-op everywhere else.

/**
 * Typd's tray mark — "the slug": one line of type, cast solid, with the
 * lines knocked out of it and the last one stopping short.
 *
 * Declared on a 16-unit grid. At the tray size one unit is one pixel, so
 * every edge but the four corners lands on a whole-pixel boundary and the
 * supersample only ever has corners to soften.
 *
 *   block    x 1 → 15   y  2 → 14    corner radius 1.5
 *   line 1   x 4 → 12   y  5 →  7    full measure
 *   line 2   x 4 →  9   y  9 → 11    62.5% of measure — the elision
 */
function trayIcon(size, dark = nativeTheme.shouldUseDarkColors) {
  const scale = 4;              // supersample, then let the downscale antialias
  const big   = size * scale;
  const unit  = big / 16;       // one grid unit, in supersampled pixels
  const buf   = Buffer.alloc(big * big * 4);

  // The overlay's own ramp. Near-white on a dark taskbar, near-black on a
  // light one, and never a third value.
  const [B, G, R] = dark ? [0xF7, 0xF5, 0xF4] : [0x1B, 0x16, 0x14];

  const BLOCK = { x0: 1, y0: 2, x1: 15, y1: 14, r: 1.5 };
  const LINES = [
    { x0: 4, y0: 5, x1: 12, y1:  7 },
    { x0: 4, y0: 9, x1:  9, y1: 11 }
  ];

  const inRect = (x, y, k) => x >= k.x0 && x < k.x1 && y >= k.y0 && y < k.y1;

  // Rounded rectangle: clamp the point into the corner-centre rectangle and
  // measure from there. Inside the straight edges the distance is zero, so
  // only the four corners ever test against the radius.
  const inBlock = (x, y) => {
    if (!inRect(x, y, BLOCK)) return false;
    const r  = BLOCK.r;
    const cx = Math.min(Math.max(x, BLOCK.x0 + r), BLOCK.x1 - r);
    const cy = Math.min(Math.max(y, BLOCK.y0 + r), BLOCK.y1 - r);
    const dx = x - cx, dy = y - cy;
    return dx * dx + dy * dy <= r * r;
  };

  for (let py = 0; py < big; py++) {
    for (let px = 0; px < big; px++) {
      const x = (px + 0.5) / unit;                 // grid coordinates
      const y = (py + 0.5) / unit;

      if (!inBlock(x, y)) continue;                // outside the slug
      if (LINES.some(l => inRect(x, y, l))) continue;   // knocked out

      const i = (py * big + px) * 4;
      buf[i] = B; buf[i + 1] = G; buf[i + 2] = R; buf[i + 3] = 0xff;
    }
  }

  return nativeImage
    .createFromBitmap(buf, { width: big, height: big })
    .resize({ width: size, height: size, quality: 'best' });
}

// The taskbar flips; so does the mark.
nativeTheme.on('updated', () => { if (tray) tray.setImage(trayIcon(16)); });
