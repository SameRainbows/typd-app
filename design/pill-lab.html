Observationsfound while building, not fixed here
  1. The magnifier draws at true resolution, the stage does not lie about DPR. The scale control multiplies with your own monitor's DPR. The hairline readout reports simulated device pixels only — on a display already at 125%, what you see at the “1.5×” setting is 1.875×. Judge the numbers, not the photons.
  2. --faint and --line in overlay.css are defined and never used. Both themes declare them; no rule reads either. Not exposed in this lab, because exposing a token nothing consumes would be a knob wired to nothing.
  3. EXIT_MS in overlay.js duplicates --dur-exit by hand. Change the exit duration here and the stylesheet is right but the dismiss timer is not. The export emits the constant alongside the CSS for exactly this reason.
  4. Cap headroom set to 0 reproduces the shipped clipping bug. overlay.js uses maxHalf = h / 2, so a bar at full level has its round caps clipped square. Set cap headroom to 0, play a session and watch the peaks go flat — that is what ships today.
  5. Backdrop saturate is exposed at 1.0. The refined pass removed it and argued why. It is a live control here because a lab that hides a rejected option cannot be used to re-test the rejection; 1.0 is off, and export omits it when it is off.
